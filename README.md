# 🛡️ LendSafe AI — Secure Loan Eligibility & Anti-Fraud Hub

> A security-focused AI engine to calculate real maximum eligible loan limits and scan suspicious loan offers for fraud signals.

---

## 📌 Overview

LendSafe AI is a full-stack web application that combines **AI-powered credit underwriting simulation** with a **real-time fraud detection scanner** — helping users in India make safer, smarter borrowing decisions.

It addresses two critical problems:
- **Information asymmetry** — most borrowers don't know their actual loan eligibility before applying
- **Loan fraud** — advance-fee scams and phishing loan offers are rampant via WhatsApp and SMS

---

## ✨ Features

### 📊 AI Eligibility Engine
- Evaluates creditworthiness using **CIBIL score**, **FOIR (Fixed Obligation to Income Ratio)**, existing EMIs, employment type, and loan type
- Supports Home, Personal, Car, and Education loans for both Salaried and Self-Employed profiles
- Outputs **approval probability**, **maximum eligible loan amount**, estimated EMI, interest rate, and risk profile
- Visual projections: EMI breakdown chart and amortization balance graph

### 🛡️ Fraud Shield Scanner
- Paste any suspicious SMS, WhatsApp message, or loan offer URL
- Scans for red flags: upfront processing fee requests, phishing domains, unsecured links, and scam language patterns
- Generates a **Scam Probability Index** with actionable recommendations

### 🏛️ Verified Banking Partners
- Lists RBI-regulated lenders with personalised rate and EMI estimates based on user inputs
- Document checklist tailored to the selected loan type
